## what is a transport network

**end users and transport (18:00)**:
* **end users**: laptop, smartphones, computers. Access via the **access network** (5g base station, ecc...). We pay an access provider to be connected.
* **communication between end users**: is end to end.
* **transport assumption**: betwen end users, there is a big network that we can call transport.
* differences between access and transport:
	* **access network**: is small, neighboroud, few kilometers.
	* **transport network**: big, a country, continent, entire world. example: satelites cover the entire world.
* **WAN**: refers to the transport network
* the customer asks to the transport network to **carry** information over the WAN.
	* **carrier**: so the transport network operator is also called also carrier.
	* is a provider for all the access networks

**examples of transport networks**:
* **submarine cables**: made of optical fiber, covering the whole earth
	* in the slide we have a physical view of the network
	* each link is a cable
* **GEANT network**: research network in europe. Made of Points of Presence (routers)
	* in the slide each link is a logical interconnection
* **Google Network**: Connects datacenters.

## differences between transport network

PoP: point of presence is the interconnection point between the end user and the transport provider.
* end user: sends its flow to it. $f_{i}$
* PoP: sends $\sum f_{i}$ (all the input, from different end users) into the transport network
* **aggregated amount of traffic**: $\sum f_{i}$ might be a large amount of traffic to forward in the transport network.

**tributary flow**: is the flow generated by a certain end user, $f_{i}$

**34:40, aggregated traffic demand**: $\sum f_{i}$

> **Note**: PoP is an access point to the TN

**output for the PoP**: there is a single big traffic flow traveling from the PoP towards the Transport Network.

> **Note**: the transport network links can carry 1TB per second of data.


> **Note**: look at the traffic aggregation slide!
> - many flow from different links
> - into a big flow in a single link with high capacity

topologies:
* tree: every pair of nodes has a single path on a tree.
* ring: resilient to link failure
* mesh: is resilient and allows to share the traffic over multiple nodes

In the transport network we use mesh:
* we have to define the routing function.


**50:00 routing**: 
* function that defines the end to end path over a graph: needed because there is at least 1 path over the network. it provides 3 functions:
1. **service delivery**
2.  **service restoration**: if a link is broken we can use an alternative path
3. load balancing
