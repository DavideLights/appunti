# 2.2 Attori
L'attore e' un'entita logica esterna al sistema che interagisce direttamente con esso, tramite l'invio di messaggi.

## 2.2.1 CTF Manager (attore)
E' un sistema software esterno a BlueAgent che si occupa di gestire la competizione (punteggi, team, utenti, configurazioni, gara). Comunica con BlueAgent tramite API REST per gestire l'intero ciclo di vita delle macchine dei team, ed agisce come entita autenticata (tramite l'utilizzo di un token) per BlueAgent. 

Richiede per conto dei Giocatori il deploy delle challenge, la verifica dei container e le configurazioni per accedere alla rete tramite VPN. 

Per conto dell'autore della sfida permette la gestione dei file di configurazione delle challenge. Permette invece all'admin di gestire i container attivi, i team, e altri aspetti della gara.

Piu avanti, verra presentato un plugin per CTFd, che agisce come CTF Manager verso BlueAgent. 

Dunque CTF Manager e' l'unico attore per BlueAgent

Rendere il CTF Manager esterno ed indipendente da BlueAgent nella sua architettura, permette di non vincolare l'uso di BlueAgent con CTFd per esempio.
