# 2.5 CR Alternativi: CyberPatriot
È un programma di educazione nazionale per il K-12 creato dalla *Air & Space Forces Association*. I team assumono il ruolo di professionisti di cybersecurity che hanno l'obiettivo di proteggere vari sistemi entro un limite di tempo, analizzando le macchine virtuali, identificandone le vulnerabilità e mitigandole.

Il CyberPatriot Scoring System (CSS) tiene traccia della progressione del team. Un demone locale esegue controlli periodici sulla macchina per determinarne lo stato, mentre un server centrale registra i punteggi comunicando con i demoni delle macchine.

Questo sistema tuttavia è **closed-source** e solo l'**AFA** può utilizzarlo.

Le differenze tra CyberPatriot e BlueAgent sono riassunte nella seguente tabella:
| Caratteristica | CyberPatriot | BlueAgent |
| :--- | :--- | :--- |
| **Virtualizzazione** | Macchine Virtuali complete (VMware / VirtualBox) | Container di sistema leggeri (Incus) |
| **Consumo di Risorse** | Elevato (diversi GB di RAM per singola VM) | Minimo (~50 MB di RAM per container) |
| **Ambiente di Rete** | Singola VM isolata | Topologia multi-container in LAN virtuale |
| **Motore di Valutazione** | Demone locale (CSS) all'interno della VM | Oracolo esterno in sandbox di rete isolata (OVN) |
