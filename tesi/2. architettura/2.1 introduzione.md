Si vuole presentare dunque la nostra soluzione: bluectfd. E’ costituito da:
- un plugin per **CTFd**, che implementa l'interfaccia per gestire le challenge patch
- blueagent: un servizio HTTP che implementa le API per la gestione delle challenge.

**blueagent** e' costruito usando **FastAPI**, per gestire in modo semplice ed efficiente le richieste HTTP. 

L'host che su cui viene eseguito blueagent deve mettere a disposizione dell'architettura le seguenti componenti:
* **Kernel Linux** per la gestione delle interfacce di rete
* **OVN** per gestire la rete di verifica dei container.
* **distrobuilder**: per generare le immagini dei container in modo dichiarativo.
* **WireGuard**: per fornire una VPN come punto d'accesso ai partecipanti
* **incus/docker**: per gestire i container.


*Per comprendere passo-passo cosa permette il sistema e come lo fa sono elencati gli use cases ed i requisiti di sistema.*
