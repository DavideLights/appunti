\section{2. Introduzione a BlueAgent}\label{2-introduzione-a-blueagent}

Si vuole presentare dunque il nostro CyberRange: \textbf{BlueAgent}. Un
servizio \emph{HTTP} che implementa delle \emph{API} per la gestione e
la verifica delle macchine a partire da definizioni \emph{IaC}. Queste
API potranno poi essere sfruttate ed implementate da qualsiasi
applicativo per gestire le challenge, come per esempio un plugin per
CTFd che vedremo in seguito.

\textbf{BlueAgent} e\textquotesingle{} basato \textbf{FastAPI}, per
gestire in modo semplice ed efficiente le richieste HTTP.

L\textquotesingle host che su cui viene eseguito BlueAgent deve mettere
a disposizione dell\textquotesingle architettura le seguenti componenti:

\begin{itemize}
\tightlist
\item
  \textbf{Debian 13 ed il Kernel Linux}: per la gestione delle
  interfacce di rete
\item
  \begin{itemize}
  \tightlist
  \item
    \passthrough{\lstinline!nftables!}: per gestire le regole di inoltro
    nel Kernel
  \end{itemize}
\item
  \textbf{ZFS}: filesystem che supporta il meccanismo
  \passthrough{\lstinline!COW!}.
\item
  \textbf{OVN ed Open vSwitch}: per gestire la rete di verifica dei
  container.
\item
  \textbf{distrobuilder}: per generare le immagini dei container in modo
  dichiarativo.
\item
  \textbf{WireGuard}: per fornire una VPN come punto
  d\textquotesingle accesso ai partecipanti
\item
  \textbf{Incus}: per la gestione dei container.
\end{itemize}

Il codice in Python che implementa BlueAgent usa i seguenti moduli:

\begin{itemize}
\tightlist
\item
  \textbf{uv}: per gestire in modo semplice ed efficace il
  \passthrough{\lstinline!venv!} ed i pacchetti richiesti da BlueAgent
\item
  \textbf{pydantic}: per modellare e validare le strutture dati
  utilizzate frequentemente.
\item
  \textbf{filelock}: per implementare il lock delle risorse in caso di
  accesso concorrente.
\item
  \textbf{aiosqlite}: per interfacciarsi con il database.
\end{itemize}

\emph{Per comprendere passo-passo cosa permette di fare il sistema e
come lo fa sono elencati gli use cases ed i requisiti di sistema.}
